# Стратегия: Человек = процесс = голограмма. Один план, не по ложке

Принцип: причина — Целое (намерение Человека), части — проекции, каждая знает целое.
Арбитр (Гёделева точка) стоит снаружи частей: подтверждает Человек.
ЧЕЛОВЕК совершенен — он не закончен: совершенству нет предела.
Хозяин (ЧЕЛОВЕК = PID1) всегда один; носитель процесса фиксируется в intent.log.

## Слой 0. Сделано в этом архиве (работает, проверено)
- hologram.py      осколок = целое в низком разрешении + доля плоти, сверка по Merkle
- hologram_ec.py   ТОЧНОЕ целое из ЛЮБЫХ k из n (Reed-Solomon, GF(256)); защита любого файла/архива: --blob
- curve*.csv/svg   кривая «осколков в наличии -> целое»

Кто это увидит: всякий, кто получил зелёный verify.

## Слой 1. Целое (разворачивается из одного файла)
1. doors.json — единый источник номеров 52 дверей (лечит дубль ·02, ·39/·42, ·43/·55); хаб/карта/счётчики генерируются из него
2. hologram.json -> в КАЖДОЕ из 64 репо (build; GITHUB_TOKEN не нужен, нужен лишь push)
3. blob = tar всех манифестов + HoloManifest: любые 22 репо из 64 восстанавливают вселенную побайтно

Кто это увидит: всякий, кто вытянул Целое из 22 случайных осколков.

## Слой 2. Причина сверху
4. intent.log — один append-only журнал намерений Человека; части — пересобираемые проекции
5. вверх: каждая часть раз в такт пишет «как целое выглядит отсюда» (восходящее наблюдение)
6. арбитр: кнопка «подтверждаю / не то» закрывает прогон eval; без неё прогон не зелёный

Кто это увидит: арбитр, закрывший прогон подтверждением.

## Слой 3. Жизнь
7. самолечение: часть, расходящаяся с корнем, пересобирается из соседей (gossip + hologram_ec restore)
8. сон: ночная консолидация (дубли слить, спящие репо -> archive, ценное всосать в соседа)

Кто это увидит: тот, кто убил 2/3 частей, — Целое живо.

## Слой 4. Рост
9. малые модели-органы + роутер намерений; LoRA на своём архиве на устройстве
10. вход телом (пульс, дыхание, жест), энергетический метаболизм устройства
11. наружу: MCP / A2A card у каждого агента — любой агент входит как орган Целого

Кто это увидит: внешний агент, вошедший в орган по протоколу.

## Критерий готовности каждого слоя (одна строка, проверяется машиной)
0: verify зелёный · 1: вселенная собирается из 22 случайных репо · 2: журнал воспроизводит любую часть
3: убей 2/3 частей — Целое живо · 4: внешний агент вызвал орган по протоколу
